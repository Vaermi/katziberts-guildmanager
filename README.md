# 🐈‍⬛ Katziberts Guildmanager

**Guild management, character information, and profession tracking for World of Warcraft Forever.**

Katziberts Guildmanager is an in-game addon developed by **Katziberts**, a Horde guild in World of Warcraft Forever.

The addon brings guild-related information and management features together in one place.

## Overview

Katziberts Guildmanager is the central guild addon within the Katziberts software ecosystem.

It is designed to provide access to guild information, character data, professions, and recipes directly inside World of Warcraft Forever.

Unlike standalone quality-of-life addons, Guildmanager focuses on features related to guild organization and character information.

## Planned Features

### Guild Management

Guild-related functionality for organizing and accessing relevant information directly in-game.

### Character Information

Access to character-related information as part of the guild management system.

### Professions and Recipes

Profession and recipe information to support coordination between guild members.

Planned functionality includes:

- Overview of character professions
- Information about known recipes
- Access to profession and recipe information within the guild

## World of Warcraft Integration

Katziberts Guildmanager is designed specifically for the World of Warcraft Forever client.

The addon runs inside the game and uses the interfaces available to WoW addons.

Feature availability and implementation details depend on the capabilities of the supported game client.

## Distribution

Katziberts Guildmanager will be available through two independent download options.

### Katziberts Addon Manager

Players can discover, download, install, and update Guildmanager through the Katziberts Addon Manager for Windows.

### Katziberts Website

Guildmanager will also be available as an individual addon download through the official Katziberts website.

Using the Addon Manager is optional.

Players who install the addon manually are responsible for checking for updates and installing new versions themselves.

**Website:** https://katziberts.at

## Katziberts Ecosystem

Guildmanager is one of several independently developed Katziberts projects.

Related projects include:

- **Katziberts Member Portal** – The guild's web-based member platform
- **Katzbot** – The guild's Discord bot
- **Katziberts Addon Manager** – Windows application for addon discovery, installation, and updates
- **PetRadar** – Hunter pet encyclopedia and stable overview
- **Funkelblick** – Quest-related object highlighting

Each addon is maintained in its own repository and follows an independent release cycle.
